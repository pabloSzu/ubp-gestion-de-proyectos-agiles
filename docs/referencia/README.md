# Referencia de trabajo del workspace

Esta carpeta conserva una copia de las reglas generales vigentes al 25 de septiembre de 2026 para que el repositorio de Gestión de Proyectos Ágiles pueda comprenderse fuera del workspace completo.

## Orden de consulta

1. `AGENTS-workspace.md`: propósito, límites y decisiones confirmadas.
2. `_REGLAS-GENERALES/PAQUETE-OBLIGATORIO.md`: lista cerrada de materiales que Pablo debe entregar.
3. `_REGLAS-GENERALES/ESTRUCTURA-MATERIA.md`: carpetas y estructura común de entregables.
4. `_REGLAS-GENERALES/ESTILO-EDITORIAL.md`: narrativa, separación de contextos y diseño Word.
5. `_REGLAS-GENERALES/FLUJOS/`: programa, contenido, glosario, microobjetivos, actividades, evaluaciones y presentaciones.
6. `_REGLAS-GENERALES/CONTROL-DE-CALIDAD.md`: comprobaciones de Word y PowerPoint.
7. `_REGLAS-GENERALES/VERSIONADO-Y-ENTREGA.md`: respaldo, Git y entregas institucionales.

Dentro del workspace completo prevalecen los originales ubicados en `UBP-Materias/_REGLAS-GENERALES/`. Si esas reglas cambian, esta copia debe volver a sincronizarse antes del siguiente commit de la materia.
